# Unmapped – Rechtliches

Datenschutzerklärung und Impressum der App Unmapped, veröffentlicht mit GitHub Pages:

- https://maxinho107.github.io/unmapped-legal/datenschutz/
- https://maxinho107.github.io/unmapped-legal/impressum/

Die Seiten werden im App-Repo aus `lib/features/settings/legal_texts.dart` erzeugt
(`dart run tool/legal_site/build.dart`, Ausgabe in `docs/legal_site/`) und hierher kopiert.
Bitte nicht von Hand ändern, sonst weichen sie vom Text in der App ab.
